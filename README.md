# 🤖 Team Task Telegram Bot (aiogram v3 + SQLite3)

Асинхронный Telegram-бот для совместной командной работы, позволяющий вести общий список задач, просматривать его и выгружать в удобном формате CSV для открытия в Excel. 

Проект спроектирован с использованием современного фреймворка **aiogram v3**, базы данных **SQLite3** и имеет чистую модульную структуру, идеально подходящую в качестве примера для новичков.

---

## 🌟 Основные возможности

* **Приветствие и интерактивное меню** `/start`: бот встречает пользователя и выводит постоянное меню с кнопками.
* **Добавление задач** `/add`:
  * *Быстрое:* `/add Текст задачи` — мгновенное добавление.
  * *Интерактивное:* при вводе команды без аргументов или нажатии кнопки «➕ Добавить задачу» запускается пошаговый режим ввода (FSM - Finite State Machine).
* **Просмотр задач** `/list`: вывод общего списка задач в чат в красивом пронумерованном HTML-формате с указанием автора и времени добавления.
* **Экспорт в CSV** `/list_csv`: отправка актуального списка в виде `.csv` файла с корректной кодировкой UTF-8 BOM (чтобы русский текст без проблем открывался в Microsoft Excel).
* **Безопасность**: все чувствительные данные (токен бота) вынесены в файлы окружения `.env`.
* **Защита от сбоев**: реализована обработка конфликтов вебхуков и автоматическая настройка вывода UTF-8 для стабильной работы на серверах под управлением Windows.

## 🛠️ Технологический стек

* **Язык программирования:** Python 3.10+
* **Фреймворк:** [aiogram v3](https://docs.aiogram.dev/en/latest/) (асинхронная библиотека для Telegram Bot API)
* **База данных:** SQLite3 (встроенная в Python)
* **Работа с конфигурацией:** `python-dotenv` (загрузка переменных из `.env` файлов)

## 🚀 Быстрый запуск

### Шаг 1. Создание бота в Telegram
1. Откройте Telegram и найдите официального бота [@BotFather](https://t.me/BotFather).
2. Запустите его и отправьте команду `/newbot`.
3. Укажите название бота и его уникальный никнейм (должен заканчиваться на `_bot`).
4. Скопируйте полученный **HTTP API Токен** (выглядит как `123456789:ABCdefGh...`).

### Шаг 2. Подготовка файлов проекта
1. Сделайте копию файла конфигурации `.env.example` и назовите её `.env`:
   ```bash
   cp .env.example .env
   ```
   *(На Windows в PowerShell: `copy .env.example .env`)*

2. Откройте файл `.env` в текстовом редакторе и вставьте ваш токен:
   ```env
   BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
   DB_PATH=tasks.db
   ```

### Шаг 3. Установка библиотек
Рекомендуется использовать виртуальное окружение. В терминале в корне проекта выполните:

**На Linux/macOS:**
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

**На Windows:**
```powershell
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
```

### Шаг 4. Запуск бота
Запустите главный скрипт:
```bash
python main.py
```

В консоли вы увидите подтверждение успешного запуска:
```text
[БД] База данных SQLite успешно инициализирована.

========================================================
[*] Бот успешно запущен и начал опрашивать сервера Telegram!
Откройте Telegram, найдите вашего бота и введите /start
Для остановки бота нажмите: Ctrl+C
========================================================
```

## 📊 Таблица базы данных (SQLite3)

При первом запуске бот автоматически создаёт файл базы данных `tasks.db` и таблицу `tasks` со следующей структурой:

| Имя поля | Тип данных | Описание |
| :--- | :--- | :--- |
| `id` | `INTEGER` | Первичный ключ (автоинкремент) |
| `text` | `TEXT` | Текст самой задачи |
| `user` | `TEXT` | Полное имя пользователя и его `@username` |
| `created_at` | `TIMESTAMP` | Дата и время создания (подставляется СУБД по умолчанию) |
